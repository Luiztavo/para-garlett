# Para Garlett — 9 años

Página de aniversario para Garlett. Se publica con GitHub Pages desde la raíz de la rama `main`.

Contenido completo de la exportación:
- `index.html` — la página (rutas relativas, lista para servirse en `luiztavo.github.io/para-garlett/`)
- `assets/` — 29 fotos (`foto-01.jpg` … `foto-29.jpg`), la canción `cancion.mp3` y el código QR `qr-github.png` que apunta a esta misma página
- `.nojekyll` — para que GitHub Pages sirva los archivos tal cual

El QR de la tarjeta Polaroid apunta a https://luiztavo.github.io/para-garlett/
